# Technical Fight 3D

Protótipo original de luta 3D 1x1, inspirado no ritmo de jogos de luta arcade.

## Controles
- A / D: mover
- J: soco
- K: chute
- L: defesa
- R: reiniciar luta
- No celular, use os botões na tela.

## Rodar
Abra `index.html` em um servidor estático. O projeto também está preparado para deploy direto na Vercel.

Sem personagens, músicas ou assets copiados de Tekken; esta é uma implementação original.
